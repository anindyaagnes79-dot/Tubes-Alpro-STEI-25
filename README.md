# Tubes IF1210 - F02 Search

## Deskripsi Singkat
Implementasi fitur pencarian URL berbasis awalan (*prefix*) menggunakan struktur data ADT List dengan array statis.

## Cara Menjalankan (WSL/Linux)
1. Buka terminal di folder ini.
2. Ketik `make` untuk kompilasi.
3. Ketik `./main` untuk menjalankan program.
4. Gunakan `make clean` jika ingin menghapus file hasil kompilasi.
